# Android APK preparation notes

This project cannot be compiled into an APK inside this environment because Android Studio, the Android SDK, Java JDK, and Gradle are not installed. The steps below let you build a real APK externally.

## Option A: Bubblewrap (Trusted Web Activity, recommended)
1. Install Node.js (already available) and Java JDK 17+.
2. Install Android SDK command-line tools and set ANDROID_HOME.
3. Run:
   `npx @bubblewrap/cli init --manifest=https://dipesh20710.github.io/dipseditz-website/manifest.webmanifest`
4. Follow the prompts (package id `in.dipseditz.app`, app name `Dips Editz`, version `1.0`).
5. Build: `bubblewrap build`
6. Sign the APK with your keystore; note the SHA-256 fingerprint.
7. Update `.well-known/assetlinks.json` with that fingerprint and upload it to GitHub.
8. Upload the APK (e.g. to GitHub Releases) and set `APK_DOWNLOAD_URL` in `script.js`.

## Option B: PWABuilder (no local Android toolchain)
1. Visit https://www.pwabuilder.com
2. Enter https://dipesh20710.github.io/dipseditz-website/
3. Generate and download the Android package (APK/AAB).
4. Upload the APK to GitHub Releases and set `APK_DOWNLOAD_URL`.

## Option C: Android Studio WebView
1. Create a new Android project (Empty Views Activity).
2. Add a WebView loading https://dipesh20710.github.io/dipseditz-website/.
3. Enable JavaScript, DOM storage, and file access as needed.
4. Build a signed APK/AAB.

## After building the APK
- Set `APK_DOWNLOAD_URL` in `script.js` to the public APK download URL.
- Re-upload `script.js` (and any changed files) to GitHub.
- The "Download APK" button will then trigger a real download.

No APK is included in this repository and none has been generated by this tool.

# Dips Editz — Website

A premium, dark black & purple website for the Dips Editz YouTube channel.
Built with HTML, CSS, and JavaScript only. Now a Progressive Web App (PWA).

## Preview in Chrome

### Option 1 — Open the file directly
1. Open Chrome.
2. Press `Ctrl + O` (or drag the file into the window).
3. Select `index.html` inside this folder.

> Service workers require a secure context. For full PWA testing use Option 2.

### Option 2 — Local server (recommended)
```powershell
cd "C:\Users\dipes\Python\dipseditz-website"
python -m http.server 8000
```
Then open Chrome and visit: http://localhost:8000

## Test the PWA
1. Open Chrome DevTools (F12) → **Application** tab.
2. **Manifest**: check name "Dips Editz", icons 192/512, start_url, scope, theme/background colors.
3. **Service Workers**: confirm `service-worker.js` is registered and activated for scope `/dipseditz-website/`.
4. **Cache Storage**: verify `dipseditz-v1` contains the app shell.
5. Throttle network to Offline and reload — the offline fallback page should appear for navigations; cached assets still load.
6. Click "Install App" when the prompt appears, or use Chrome menu → "Install Dips Editz".

## Publish to GitHub Pages
Upload these files to the repository root (replace existing):
- index.html
- style.css
- script.js
- manifest.webmanifest
- service-worker.js
- offline.html
- app-icon-192.png
- app-icon-512.png
- spiderman-logo.png (already there)

Enable GitHub Pages on the main branch. The site runs at:
https://dipesh20710.github.io/dipseditz-website/

## Install the PWA
- Desktop (Chrome/Edge): click "Install App" or the install icon in the address bar.
- Android (Chrome): menu → "Install app" / "Add to Home screen".
- iOS (Safari): Share → "Add to Home Screen".

## Package as Android APK later (separate workflow)
This PWA is not itself an APK. To create an Android APK later, use a packaging tool such as:
- Bubblewrap (Trusted Web Activity): `npx @bubblewrap/cli init --manifest=https://dipesh20710.github.io/dipseditz-website/manifest.webmanifest`
- PWABuilder (https://www.pwabuilder.com) to generate an APK/AAB.
- Capacitor or Cordova wrapping the hosted site.

These are separate steps and are not included in this project.

## Notes
- No backend, database, or API keys are used.
- Booking requests are prepared as emails; the customer sends them.
- No customer data is cached or stored by the service worker.

# Dips Editz — Website

A premium, dark black & purple website for the Dips Editz YouTube channel.
Built with HTML, CSS, and JavaScript only.

## Preview in Chrome

### Option 1 — Open the file directly
1. Open Chrome.
2. Press `Ctrl + O` (or drag the file into the window).
3. Select `index.html` inside this folder.
4. The site opens locally.

> Some browsers restrict certain features when opened via `file://`. If anything looks off, use Option 2.

### Option 2 — Local server (recommended)
Using Python (already installed):
```powershell
cd "c:\Users\dipes\Python\dipseditz-website"
python -m http.server 8000
```
Then open Chrome and visit: http://localhost:8000

Using Node (if installed):
```powershell
npx serve .
```

Using VS Code: install the "Live Server" extension, right-click `index.html` → "Open with Live Server".

## Customize

- **YouTube channel URL**: already set in `script.js` → `CHANNEL_URL`.
- **Featured videos**: edit the `VIDEOS` array in `script.js`. Replace `YOUR_VIDEO_ID_1` etc. with real YouTube video IDs (the part after `v=` in a video URL).
- **Social links**: edit the `SOCIAL` object in `script.js`.
- **Text / about**: edit `index.html`.
- **Colors**: edit CSS variables at the top of `style.css`.

## Files
- `index.html` — page structure
- `style.css` — styling (dark black + purple theme)
- `script.js` — interactivity, video rendering, animations
